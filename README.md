# Espanso 단축어 분류

- `:` 목표·의도·맥락 파악, 계획·설계, 선택과 우선순위, 업무 정리.
- `;` 구현 코드·로그·실행 결과를 근거로 결함을 찾거나 수정·검증하는 엔지니어링 작업.
- 이름에 리뷰가 있어도 계획·설계·일반 결과물 검토는 `:`, 구현 검토는 `;`를 쓴다.
- 경계 항목: `:적대적리뷰`는 일반 결과물 판단, `;디테일`·`;문제발견`은 실제 기능과 동작의 결함 탐색, `;병목파악`은 시스템 흐름과 측정 근거의 분석이다.
- 접두사는 분류이며 실행 권한을 뜻하지 않는다. 각 문구의 승인·수정 제한을 그대로 따른다.

## 등록 목록

- : : `:문제분해`, `:목표성과`, `:적대적리뷰`, `:설계리뷰`, `:브레인스토밍`, `:의도확인`, `:맥락파악`, `:플랜점검`, `:외부리뷰`, `:나복귀`, `:전체우선`, `:선택결과`, `:후속점검`, `:반복정리`, `:pdca현황`, `:병목점검`
- ; : `;결과검증`, `;디테일`, `;원인파악`, `;문제해결`, `;병목파악`, `;코드리뷰`, `;QA`, `;문제발견`

## 줄바꿈과 공백 작성 원칙

- 여러 줄 문구는 `replace: |-`로 저장해 입력 시 줄바꿈이 유지되도록 한다. `>-`는 줄바꿈을 공백으로 합치므로 사용하지 않는다.
- 문장은 끝에서 줄을 나누고, 목적·검토 내용·제약·출력 형식처럼 주제가 바뀌면 빈 줄 하나로 구분한다.
- 제목과 목록 사이의 빈 줄, 하위 목록의 들여쓰기를 유지한다. 줄 끝 공백과 불필요한 연속 빈 줄은 제거한다.
- 서식만 수정할 때는 단축어 이름·순서·문구·명령·경로를 유지한다. 실제로 펼쳐지는 문구를 파싱해 공백 외의 내용이 바뀌지 않았는지 확인한다.
- Mac의 실제 입력 동작과 macOS 텍스트 대치 동기화는 별도로 확인한다.

## 계획 점검과 외부 리뷰

- `:플랜점검`: 현재 대화에서 Plan 문서의 요구사항 일치, 실현 가능성, 범위와 완료 기준을 사전 점검한다.
- `:외부리뷰`: 다른 AI 도구에 같은 계획을 전달해 독립적으로 검토하고, 받은 의견의 타당성을 평가한다. 사전 점검 결과가 있으면 함께 전달하되 결론을 그대로 믿지 않도록 한다.

두 단축어 모두 검토와 개선안 제시만 수행하며, 사용자 확인 전에는 계획 문서·코드를 수정하거나 다음 단계로 진행하지 않는다. 외부 도구를 실행할 수 없으면 실행 불가 사실과 전달용 리뷰 요청문을 제공한다.

## macOS 텍스트 대치 보조 항목

- `:list`: 전체 단축어 목록.
- `:설계`: `:설계리뷰`와 같은 문구를 사용하는 기존 무접두사 별칭의 새 이름.
- Espanso 단축어는 이 저장소를 정본으로 관리하며, macOS 텍스트 대치는 별도로 동기화한다. 이전 세미콜론 이름 6개는 새 콜론 이름으로 대체한다.

### `:병목점검` 추가하기

- [macos/bottleneck-check.plist](macos/bottleneck-check.plist)는 `:병목점검` 한 항목을 담은 텍스트 대치 가져오기 파일이다.
- GitHub에서 파일을 내려받은 뒤 **시스템 설정 → 키보드 → 텍스트 대치** 창에 드래그하고 **완료**를 누른다.
- 가져온 뒤 `:병목점검`을 입력해 아래 세 문장과 줄바꿈을 확인한다. 실제 Mac에서의 가져오기와 입력 동작은 별도 확인이 필요하다.

```text
확인된 결과: 실제로 어디까지 성공했는가?
현재 병목: 목표 달성을 가장 크게 막는 문제는 무엇인가?
다음 검증: 무엇을 해보면 그 문제의 해결 가능성을 판단할 수 있는가?
```

가져오기 절차: [Apple 공식 안내](https://support.apple.com/ko-kr/guide/mac-help/mchl2a7bd795/mac)
